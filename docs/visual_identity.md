# Visual Identity Notes

These notes keep the GitHub presentation visually consistent with the article:
scientific, technical, and modern, without turning the repository into a
marketing page.

## Design Direction

- Primary mood: geospatial, analytical, soil science, Amazon, reproducibility.
- Avoid: decorative clutter, unsupported claims, flashy gradients, and visual
  elements that compete with the article.
- Use visual elements as orientation: title, badges, raster preview, workflow,
  and data provenance.

## README Assets

## Inspiration

The structure borrows from mature scientific/software projects: strong project
identity at the top, informative badges, a concise explanation, fast links to
documentation, and clear boundaries around support and reproducibility.
