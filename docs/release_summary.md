# Release Summary Draft

## Suggested Tag

`v1.0.0-cleanup`

## Suggested Release Title

Cleaned article-support repository for western Amazon SOC stock mapping

## Suggested Release Notes

This release organizes the R scripts and documentation supporting the article
"High-resolution mapping of soil carbon stocks in the western Amazon"
(Geoderma Regional, 2024).

Highlights:

- Article-first README with scientific visual identity.
- Scripts grouped by data preparation, modeling, prediction, figures/maps, and
  legacy methodological context.
- Traceability table linking article sections and figures to supporting scripts.
- Zenodo links for final map products.
- Metadata files for citation, CodeMeta, and Zenodo.
- Explicit notes on non-portable paths, missing local helpers, and large data
  products excluded from Git.

This release is intended for transparency, provenance, and article support. It
does not claim to be a one-command rerunnable pipeline.
